# Storyboard template

Copy per video. The totals at the bottom must match the format target before
any capture starts.

## Header

```
project         
format          demo | presentation | short | tutorial
frame           16:9 1920x1080 | 9:16 1080x1920
takeaway        one sentence, agreed by the owner on (date)
next action     what the viewer does after watching
rate            words per minute the narration is timed at, and how it was
                measured
target          length range from video-core section 3, or the destination's rule
```

## Beats

| # | Name | Picture | Words | On screen | Pause (s) | Duration (s) | Source |
|---|---|---|---|---|---|---|---|
| 1 | | capture / title / diagram / code / card | | | | | |
| 2 | | | | | | | |

Duration = words in the beat / rate x 60, plus the pause.

## Totals

```
words           
duration        sum of the beats, in seconds
within target   yes | no, and what is cut if no
```
