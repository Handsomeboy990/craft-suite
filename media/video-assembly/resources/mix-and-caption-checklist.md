# Mix and caption checklist

## Mix

```
target          integrated LUFS, true peak dBTP, from (destination page, date)
                or the video-core default
measured before integrated, range, true peak, with the command used
measured after  integrated, range, true peak, after the two-pass normalisation
```

- [ ] Voice, music and effects kept as separate stems.
- [ ] Music ducked under every line, with short fades.
- [ ] No clipped first word, no unintended silence at the start or the end.
- [ ] Every music track and effect licensed, recorded in the rights record.
- [ ] Final mix within target on the second measurement.

## Captions

- [ ] Built from the voice transcript, not from automatic transcription.
- [ ] Each caption at most two lines, broken at phrase boundaries.
- [ ] Each caption on screen long enough to read.
- [ ] Timed to the real audio of its clip; no drift at the end of the video.
- [ ] WebVTT and SubRip files written; burned in for shorts, inside the safe
      area.
- [ ] Watched once with captions and sound on; every mismatch fixed.

## Chapters, tutorials only

- [ ] One chapter per task, titled with the task.
- [ ] Start times match the cut.
- [ ] Format matches the destination's chapter format.

## Render

- [ ] Render tools verified installed, versions recorded.
- [ ] Master rendered with one documented command from the edit decision list.
- [ ] Commit of the sources recorded with the master.
