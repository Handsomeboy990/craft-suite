# Rights and brief record

Filled before the first capture, kept with the video's sources, and updated
when the scope changes. A field left empty is a question for the owner, not a
default.

## Brief

```
project         name, repository or URL, version or commit shown
owner           the person or team who can agree for the project, and how to
                reach them
format          demo, presentation, short or tutorial
destination     where it will be shown: a platform, an event, a jury, a site;
                its current published rules read on (date)
audience        who watches, what they already know
takeaway        the one thing a viewer must remember, in one sentence
language        media.video_language, or language.document_output
voice           media.voice_provider and media.voice_model, as resolved
deadline        when the owner needs the cut
```

## Permission

```
agreed by       full name, role in the project
agreed on       date
agreed how      the message, email or signed note it was given in, kept
for             this video, this format, this destination
may appear      screens, features, data, repository views agreed
must not appear anything confidential, unreleased, personal, internal
review          the owner reviews the cut before delivery: yes, by (date)
credits         the attribution text the owner asked for
```

## Voice

```

engine, voice   as resolved, with version

```
