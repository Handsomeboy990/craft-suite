# Example: a dashboard, shortlisted not chosen for the user

A project needs an admin dashboard, in its existing framework, for a commercial
product with a defined brand. The naive move is to grab the first impressive
dashboard template and ship it. This skill does otherwise.

## Understand the project first

```
type       an admin dashboard: tables, forms, charts, an app shell
stack      the project's framework and styling approach, fixed
features    role-based navigation, data tables, a settings area
identity    an established brand: a serif display face, a restrained palette,
            not the template's neon-on-dark default
licence     commercial use required; a paid template is acceptable if its
            licence permits per-project commercial use
```

## Judge the candidates

```
Template A   impressive, but in a different framework: a rewrite, not a head
             start. Dropped on fit.
Template B   right stack, MIT licence, clean and restrained, accessible tables.
             A real candidate.
Template C   right stack, but the whole vibe-coded cluster: neon gradients, a
             bento grid, a sparkle logo, fake testimonials in the demo.
             design-authenticity flags it; not clean. Dropped.
Template D   right stack, beautiful, but a paid licence that forbids use in a
             product sold to others. Its licence does not permit this use.
             Dropped.
```

## Shortlist, and let the user choose

```
presented   B, and one more clean, correctly licensed candidate, each with its
            licence, its accessibility, and what customising it to the brand
            would take
the choice  the user picks, on the fit to the brand and the acceptable licence,
            which are theirs to decide, not the skill's
```

## After the choice

The chosen template's MIT licence is confirmed to permit commercial use, its
attribution kept in the source, and its provenance recorded. Then customisation:
the brand's serif and palette become the project's tokens, the placeholder copy
and stock charts are replaced with real content, and the generic markers the
template carried are replaced with intentional choices. What ships is the
project's dashboard on a licensed foundation, not a recognisable clone of the
template's demo.
