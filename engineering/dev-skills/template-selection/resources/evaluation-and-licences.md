# Evaluation grid and licence notes

## The evaluation grid

Score each candidate; the winner is not the prettiest thumbnail.

| Axis | Green | Red |
|---|---|---|
| Fit | right type, right stack, has the features needed | wrong stack (a rewrite), missing the core feature |
| Cleanliness | reads as designed; few or no generic-default tells | the whole vibe-coded cluster, called modern |
| Licence | permits the use, commercial where needed, terms the project can meet | forbids the use, or paid and unbought, or unclear |
| Quality | maintainable, current dependencies, accessible, survives real content | a demo that breaks on real data, stale dependencies |
| Customisation cost | tokens and content swap cleanly into the project | reworking the whole thing to remove the template's identity |

Cleanliness is judged with `design-authenticity`: a template carrying the
gradient, the bento grid, the default font, the hover-everywhere motion and the
fabricated testimonials is not clean; it is the generic default with a nice
screenshot.

## Licence notes

A template has a licence, and using it is using it under that licence.

```
permissive    MIT, Apache and similar: broad use including commercial, usually
              with attribution kept in the source. Read the exact terms.
copyleft      some licences require derivative work to carry the same licence;
              check whether that is acceptable for the project
paid          a marketplace template is licensed by purchase, often per-project
              or per-seat, sometimes forbidding resale or redistribution. Buy
              it, and meet the seat and project terms.
attribution   where required, the attribution is rendered as the licence
              specifies; removing it is a violation
no licence    a design or template with no stated licence grants no permission;
              absence of a licence is not permission, it is the opposite
```

Record the template, its source and its licence, so the project can prove its
provenance if asked. A template used against its licence is a legal exposure the
project carries, not a shortcut it took.
