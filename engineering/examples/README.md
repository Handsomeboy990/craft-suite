# examples

Worked examples for the engineering tree, kept as artefacts so the process is
visible, not only described.

| Example | What it shows |
|---|---|
| [delivery-link-shortener](delivery-link-shortener/) | the fourteen delivery phases run end to end on one small application, with the four approval gates |

An example is a record of a real run: the deliverable each phase produces, at
the size the project justifies. It is not a template to copy field by field.
The writing tree keeps its own worked example under `writing/examples/`.
