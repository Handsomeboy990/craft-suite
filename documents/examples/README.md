# exemples

Exemples travailles de l'arbre documents, gardes comme artefacts pour que le
procede soit visible, pas seulement decrit.

| Exemple | Ce qu'il montre |
|---|---|
| [jeu-conges](jeu-conges/) | un meme sujet ecrit pour trois lecteurs differents, chaque document passe a la porte qualite en huit points, plus une verification de rendu PDF |

Un exemple est la trace d'un vrai passage : le livrable que chaque skill
produit, a la taille que le projet justifie. Ce n'est pas un gabarit a recopier
champ par champ. L'arbre writing garde son propre exemple sous
`writing/examples/`, l'arbre engineering le sien sous `engineering/examples/`.
