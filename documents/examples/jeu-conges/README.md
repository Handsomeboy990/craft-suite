# Jeu de documents : CongesPro

Un vrai passage de l'arbre documents, garde comme artefacts. Un meme sujet
ecrit pour trois lecteurs, pour montrer la regle centrale de document-core :
le lecteur decide la structure, jamais le sujet. Chaque document passe la porte
qualite en huit points avant livraison.

Sujet, volontairement fictif : l'entreprise Ficto a mis en service CongesPro,
un systeme interne de demande de conges qui remplace un ancien tableur.

| Fichier | Lecteur | Skill |
|---|---|---|
| [01-guide-utilisateur.md](01-guide-utilisateur.md) | le salarie qui pose un conge | user-documentation |
| [02-manuel-technique.md](02-manuel-technique.md) | l'administrateur IT qui exploite l'outil | technical-writing |
| [03-rapport-de-deploiement.md](03-rapport-de-deploiement.md) | la responsable RH qui decide de la suite | report-writing |
| [04-portes-et-verification-pdf.md](04-portes-et-verification-pdf.md) | la trace des portes, de la regle du lecteur et de la verification PDF | document-core, pdf-production |

Le meme fait, par exemple les deux incidents du premier mois, apparait dans les
trois documents mais formule pour chaque lecteur : une consigne de contournement
pour le salarie, une procedure de depannage pour l'administrateur, une ligne de
bilan pour la decideuse. C'est la separation par lecteur, pas de la recopie.

Les mentions [A CONFIRMER] sont voulues : document-core interdit d'inventer un
fait, donc les manques (proprietaire du document, canal de signalement, durees)
sont marques plutot que combles par du plausible.
