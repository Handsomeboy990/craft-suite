# Surface inventory fields

Every recorded asset carries all of these, or it is not recorded.

- asset: host, service, technology or version
- method: the passive source named, or the active step logged
- scope: in scope | out of scope (never probed)
- first seen: date, and the run that found it
- confidence: and what would raise it
- status: observed | inferred (marked) | assumption (marked, never promoted)

Active-step log, per request: tool and flags, target, time, authorizer.
