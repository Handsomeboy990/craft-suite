# Moodboard record

A moodboard is evidence of direction. Every image or link on it is a
reference that belongs to someone, and the record says whose, on what terms,
and what was taken from it.

## 1. The record

| Id | Reference | Where | Author or owner | Licence or terms, as stated at the source | Checked | Principle taken | Not taken | Kind |
|---|---|---|---|---|---|---|---|---|
| R1 | | URL or location | | quote or link the licence text | date | in the abstract | | direction or distance |

`Kind`:

```
direction   a reference the identity moves toward, for a principle
distance    a reference the identity must differ from, typically a brand in
            the client's own market; the "not taken" column is the point
```

## 2. Rules

- No source, no row. A reference whose origin cannot be stated is removed.
- The licence column quotes the terms found at the source, or says
  `not found`. It never says "free" or "public" from memory.
- `not found` means: direction only, linked rather than reproduced, and never
  placed in the charter, the canvas or any shared file as an image.
- A reference may be reproduced on a shared board only when its licence
  permits it, and the credit the licence requires is shown beside it.
- The principle is written in the abstract: a ratio, a rhythm, a treatment of
  light, a relationship between type and space. Never "like this site".
- Nothing is copied from a reference brand: its mark, its palette taken
  whole, its layout, its photography, its wording.
- A reference is checked on the date recorded. Terms change; the date says
  which terms were read.

## 3. Where the moodboard lives

```
canvas          on the design canvas, with only the references whose licence
                permits reproduction shown as images, the rest as links
owner link      the owner's board, read back; its references are recorded
                here like any other, with their sources asked for if missing
repository      this table, in the charter appendix or beside the tokens
```

The table is the record in every case. A board image without a row in the
table is removed from the board.

## 4. Check before sign-off

```
every row has a source                                    yes | no
every row has a licence or "not found"                    yes | no
no "not found" reference is reproduced anywhere           yes | no
every distance reference says what is not taken           yes | no
no element of the identity is traceable to a single
reference brand's mark, palette or layout                 yes | no
```
