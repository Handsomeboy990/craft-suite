# Tell catalogue

The signals from `SKILL.md` sections 2, 3 and 4, expanded with how each is
detected on a rendered page and what a considered alternative looks like. The
alternative is an illustration of intent, never a prescription: the real
replacement depends on the product's own identity.

## Visual

| Tell | Detected by | A considered choice instead |
|---|---|---|
| Violet to black gradient | the hero or section background is a diagonal purple gradient darkening to near black | a ground colour drawn from the brand, or a flat colour with a reason |
| Pure white or pure black flat | the page background is exactly white or black with no considered tone | an off-white or a near-black chosen for the brand's warmth or coolness |
| Neon on dark | saturated cyan, magenta or lime glowing on a dark ground | colour tied to meaning, used where it signifies something |
| Faded pastels | washed low-saturation tints with no dominant colour | a palette with a clear primary and a reason for the secondaries |
| Saturated band | a single bright full-width strip separating two sections | a layout that separates by space and hierarchy, not a coloured stripe |
| Bento grid | features laid out as a grid of equal rounded cards of mixed sizes | an arrangement that reflects the relative weight of the features |
| One rounded radius everywhere | every card, button and input shares the same large radius | a radius scale, or a deliberate single radius with a stated reason |
| Drop shadow on everything | every surface floats on the same soft shadow | elevation used to show real hierarchy, most surfaces flat |
| Frosted or liquid glass | translucent blurred panels over a busy background | a solid surface where legibility matters |
| Dot grid or blurred orbs | a faint dot pattern or soft coloured blobs behind the content | a background that is either plain or carries real meaning |
| Star or sparkle icon | a four-point sparkle marking anything described as smart or AI | an icon that depicts what the feature actually does |

## Typography and motion

| Tell | Detected by | A considered choice instead |
|---|---|---|
| Geist or Space Grotesk by default | the font stack is one of these with no brand reason | a typeface chosen for the product's voice, which may still be one of these if there is a reason |
| Emoji in a heading | a headline contains an emoji doing the work of hierarchy | hierarchy from type scale and weight, emoji only where it carries real meaning |
| Hover animation everywhere | every card lifts, every link shifts, on hover | motion reserved for where it communicates state or guides attention |
| Sliding arrows everywhere | the same arrow-slides-right micro-interaction on every link | one deliberate motion pattern, used consistently and sparingly |
| Transition on everything | a global transition applies to properties that should be instant | transitions chosen per interaction, instant where instant is correct |

## Content, the serious ones

| Tell | Detected by | Why it is raised regardless of the visual count |
|---|---|---|
| Fabricated testimonials | quoted praise from named people or companies with no real source | a fabricated endorsement is a false statement published on the page |
| Invented metrics or logos | numbers or customer logos presented as real but with no basis | the same, and it is the kind of claim that carries legal exposure |
| Repeated "it is not X, it is Y" | the construction used as the value proposition, more than once | a rhetorical template standing in for a real reason to care |
| Green-check features not all built | a checked feature list where some items are aspirational | a checked item is a claim; an unbuilt one overlaps with fake functionality |
| Generic three-tier pricing | three pricing columns on a product with no actual pricing | a template section shipped because the template contained it |
| No product shown | no screenshot, demo, or view of the actual thing, anywhere | the page sells something it never shows the visitor |
