# Review matrix

Who approves what before publication. The matrix is written with the client
and accepted by the person who says yes for the brand. It is part of the
editorial line, versioned with it.

## 1. Roles

```
drafter        writes the piece: an agent, a writer, the client's staff
reviewer       checks the piece against the line: pillar, vocabulary,
               never said, format; never the drafter
approver       says yes for the brand; named by role, accepted by the client
source holder  the person who holds the evidence for a claim, a figure, a
               guarantee or a name; confirms it in writing
adviser        the client's qualified adviser, in a regulated sector only;
               supplied by the client, never assumed
publisher      the owner, or whoever the owner names; the agent is never
               the publisher
```

## 2. The matrix

```
| Piece                         | Drafter | Reviewer | Approver | Also required            |
|-------------------------------|---------|----------|----------|--------------------------|
| site page                     |         |          |          |                          |
| article                       |         |          |          | source holder for facts  |
| newsletter                    |         |          |          |                          |
| social post (rules only here) |         |          |          |                          |
| any claim or figure           |         |          |          | source holder            |
| a named person or their photo |         |          |          | that person's consent    |
| a sensitive topic             |         |          |          | approver, never delegated|
| regulated-sector claim        |         |          |          | adviser                  |
```

Every cell is filled with a role, never left blank. A blank cell is the piece
that goes out unreviewed.

## 3. Rules that do not change with the client

- The drafter is never the reviewer and never the approver, agent or person.
- A claim, a figure or a guarantee is approved with the document that proves
  it, and the document is recorded.
- A person is named or shown only with their consent, recorded.
- The agent prepares and hands over. Publishing to a site, a mailing list or
  an account is not a delegation the configuration grants, so the piece goes
  to the publisher with where it goes and when.
- A refused piece names the rule of the line it broke, quoted, and goes back
  to the drafter.

## 4. Per-piece record

```
REVIEW   <piece>, <version>, <date>

Line version      <editorial line version>
Pillar            <name>
Drafted by        <role>
Reviewed by       <role>   checks: pillar | vocabulary | never said | format
Sources           <each claim or figure, with its document and holder>
Consents          <each named person, recorded where>
Approved by       <role>, <date>
Verdict           approved | refused
If refused        <the rule broken, quoted, and what is owed>
Handed to         <publisher>, <where it goes>
```
