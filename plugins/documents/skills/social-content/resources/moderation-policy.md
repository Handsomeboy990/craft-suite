# Moderation and reply policy

Written with the client before the first post, accepted by the person who
says yes for the brand, versioned with the social content plan. The agent
drafts replies; it never sends one from a real account.

## 1. Who

```
reply authority   who may answer in the brand's name, by role
complaints        who decides on a complaint, a refund, a redo
press             who speaks to a journalist or a public figure
legal             who receives a threat or a claim; the client's adviser
safety            who is reached at once for an injury or a danger,
                  including out of hours, and how
hours             when the accounts are watched, in the client's words
```

Every row is a role the client named. A blank row means the policy is not
ready.

## 2. Per kind of message

The empty cells are filled with the client. "Escalated" means the drafter of
a reply never answers it alone.

| Kind | Answered? | By whom | Within | How | Escalated to |
|---|---|---|---|---|---|
| question about the offer | yes | | | public, in the line's register | |
| praise | yes | | | public, short | |
| criticism, fair | yes | | | public, acknowledged, no argument | |
| complaint: work, money, refund | escalated | | | moved to private | the complaints role |
| abuse, harassment | no | | | hidden if the network allows, recorded | the owner |
| spam | no | | | hidden or removed, recorded | |
| legal: threat, claim, dispute | escalated | never the drafter | | no public reply | the owner, then the adviser |
| safety: injury, danger | escalated | never the drafter | at once | as the owner decides | the owner |
| press, public figure | escalated | | | as the press role decides | the press role |
| personal data shared in public | escalated | | | hidden if possible, then a private reply | the owner |

"Within" is a time the client said it can hold, in its own hours. A response
time copied from somewhere else is not a policy.

## 3. Never done

```
- delete or hide legitimate criticism because it is critical
- argue in public, use sarcasm, or reply twice to the same provocation
- disclose personal data: an order, an address, a repair, a name the person
  did not give in that thread
- promise in a reply what the line does not let a post promise
- admit fault, liability or a cause in a legal or safety matter
- reply from a real account as the agent
```

## 4. Removal record

Every hide or removal, by whoever performed it:

```
REMOVAL   <date>, <channel>

Message           <summarised, never the personal data itself>
Kind              spam | abuse | personal data | illegal content
Rule              <the line of section 2 or 3 that allows it>
Performed by      <role, a person, never the agent>
Kept              <where a copy is kept, if the client's rules say so>
```

## 5. Reply draft, as handed over

```
REPLY   <date>, <channel>, <thread link>

Kind              <from section 2>
Draft             <the exact text>
Public or private <which>
Escalated?        no | yes, to <role>, because <...>
Approved by       <role>
Action            the owner posts it from their account, or forwards it to
                  the escalation role
```
