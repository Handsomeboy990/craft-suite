# Adversarial input matrix

Concrete payloads. Each row becomes a test case for the inputs it applies to.

## Emptiness and absence

| Payload | Expected |
|---|---|
| field absent from the body | 400, not a silent default |
| `null` | 400 unless the schema declares nullable |
| `""` | 400 for a required string |
| `"   "` | 400, whitespace is not content |
| `[]` for a required non empty array | 400 |
| `{}` for a required object | 400 |

## Boundaries

| Payload | Expected |
|---|---|
| length exactly at minimum | accepted |
| length one below minimum | 400 |
| length exactly at maximum | accepted |
| length one above maximum | 400 |
| `0`, `-1`, `-0` on a positive quantity | 400 |
| `Number.MAX_SAFE_INTEGER + 1` | 400 |
| `1e309` | 400, not Infinity |
| `NaN`, `Infinity`, `-Infinity` | 400 |
| `0.1 + 0.2` style float on a money field | rejected by design, money is integer minor units |

## Type confusion

| Payload | Expected |
|---|---|
| `"5"` where a number is expected | rejected or coerced, decided and documented |
| `5` where a string is expected | rejected |
| `"true"` where a boolean is expected | rejected unless the framework coerces query params, in which case documented |
| `["a"]` where a string is expected | rejected, never joined |
| `{"toString": "x"}` where a string is expected | rejected |
| an array where an object is expected | rejected |

## Size and structure

| Payload | Expected |
|---|---|
| a 10 MB string in a name field | rejected before storage and before logging |
| an array of 100,000 elements | rejected by a maximum length |
| an object nested 1,000 levels deep | rejected by a depth limit |
| a body larger than the configured limit | 413 from the server, not an out of memory |
| duplicated JSON keys | last wins or rejected, decided explicitly |

## Text and encoding

| Payload | Expected |
|---|---|
| `"café"` with a combining accent | accepted, normalised, length counted in a stated unit |
| four byte emoji in a name | accepted or rejected by an explicit rule, never truncated mid character |
| a null byte, written `\u0000`, or any C0 control character | rejected |
| a right to left override, written `\u202E` | rejected in identifiers and filenames |
| a homoglyph domain in an email | normalised, and compared in its normalised form |
| a very long single line with no whitespace | bounded by the maximum length |

## Injection shaped

These must be stored and rendered safely rather than rejected on the basis of
their appearance, unless the field has a legitimate character allowlist.

| Payload | Expected |
|---|---|
| `Robert'); DROP TABLE students;--` | stored verbatim, parameterised query, no error |
| `<script>alert(1)</script>` | stored verbatim, escaped at the HTML sink |
| `<img src=x onerror=alert(1)>` | escaped or stripped by an allowlist sanitiser |
| `javascript:alert(1)` in a URL field | rejected by the scheme allowlist |
| `{{7*7}}` or `${7*7}` | never evaluated by a template engine |
| `../../etc/passwd` in a filename | rejected, resolved path confirmed inside the root |
| `file:///etc/passwd` in a fetched URL | rejected by the scheme allowlist |
| `http://169.254.169.254/` in a fetched URL | rejected by the host allowlist |
| `http://localhost:6379/` in a fetched URL | rejected, private ranges blocked after DNS resolution |
| `__proto__`, `constructor`, `prototype` as object keys | stripped or rejected |
| `; rm -rf /` appended to a value used in a command | no shell interpolation exists at all |
| a header value containing `\r\n` | rejected, no header splitting |

## Concurrency and repetition

| Scenario | Expected |
|---|---|
| the same request sent twice in sequence | one effect, or an explicit conflict response |
| the same request sent twice concurrently | one effect, enforced by a unique constraint or a lock |
| a replayed webhook with a past timestamp | rejected by the freshness window |
| a replayed webhook with a valid signature | processed once, idempotency key recorded |
| two concurrent updates to the same row | last writer detected, or an optimistic lock conflict |

## Files

| Payload | Expected |
|---|---|
| a `.png` extension on a PHP script | rejected, type sniffed from content |
| a valid PNG with a `.svg` extension | handled by the sniffed type, not the extension |
| an SVG containing a script element | rejected or sanitised, never served from the application origin |
| a zip bomb | rejected by an uncompressed size limit |
| a filename of 4,000 characters | rejected |
| a filename containing a path separator | sanitised, storage name generated by the server |
| a file at exactly the size limit | accepted |
| a file one byte over the limit | rejected with 413 |
